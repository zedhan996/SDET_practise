## 结论与下一步

1. 当前小样本未观察到自动断言退化，也未观察到任务通过率提升。暂保留v0为默认版本。
2. v0总耗时明显受首条慢请求影响；冷启动是可能原因，但没有加载时间或对应服务日志，不能确认为根因。
3. 排除首条后的数字仅用于观察，不能据此删除原始样本、改写正式指标或认定v1更快/更慢。
4. 若比较性能，保持服务运行、预热后交换顺序（v1再v0）重复采样。单次结果不是生产性能结论。
5. 两份报告的5条人工复核项仍为pending；本文为助手对报告的对比分析，不代替用户签署人工复核。
6. 后续将稳定的离线行为评测接入CI，以任务通过率等确定性指标设门禁，不把本轮真实模型延迟直接设为硬阈值。
